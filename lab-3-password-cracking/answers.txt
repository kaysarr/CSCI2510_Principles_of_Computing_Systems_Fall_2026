7. What the results mean:
   With 1 thread it took about 55 seconds. With 2 threads it dropped to
   about 28 seconds, so basically twice as fast. After that, adding more
   threads did not help. 4, 8, 13, and 26 threads all stayed around 28
   seconds. This is because the computer I used only has 2 cores. Only 2
   threads can really run at the same time, so the extra threads just take
   turns on those same 2 cores. So more threads only speeds things up until
   you hit the number of cores the computer has.
